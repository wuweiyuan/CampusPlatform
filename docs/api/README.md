# API 文档索引

本地基址：`http://localhost:8080`。当前静态盘点共 34 个接口，详细用例和执行状态见 [手动验收对照表](../manual-acceptance.md)。示例数据仅供说明，不是实际账户或数据记录。

| 模块 | 文档 | 说明 |
| --- | --- | --- |
| 通用错误 | [HTTP 与错误码](error-codes.md) | 当前实现的 HTTP 状态、业务码、文案及尚未统一的边界 |
| 认证 | [阶段 1](<  phase-1.md>) | 验证码、注册、登录、当前用户、退出 |
| 分类与商品 | [阶段 3](phase-3.md) | 公开分类、商品及卖家操作；分类管理另见阶段 6 |
| 收藏 | [阶段 4](phase-4.md) | 收藏、取消与分页 |
| 订单 | [阶段 5](phase-5.md) | 买卖双方查询、下单、取消、模拟付款、完成 |
| 管理员 | [阶段 6](phase-6.md) | 分类、用户、商品及只读订单管理 |
| 热门与缓存 | [阶段 7](phase-7.md) | 热门商品字段、排序、缓存与故障；不按周过滤 |
| 探测接口 | [健康检查与 ping](system.md) | 当前权限、固定返回值及限制 |

各历史文档的错误说明以错误码表的当前实现说明补充为准。阶段 1 文件名暂保留两个前导空格，避免本次无关重命名；分类管理的后续维护以阶段 6 为主。[Postman 集合和导入说明](../postman/README.md)已整理，尚未实际导入或执行完整 API 回归。
