## 阶段 4 目标与边界

- 用户可收藏、取消收藏、分页查看自己的收藏。
- 同一用户对同一商品只保留一条收藏关系；数据库唯一索引负责最终兜底。
- 只有 `ON_SALE` 商品可新增收藏；已收藏商品之后下架，仍显示在“我的收藏”中并带有状态标签。
- 收藏和取消收藏都只依据当前 JWT 中的用户 ID，客户端不得传入或指定任意用户 ID。
- 不实现收藏夹分组、批量取消、通知、下单或订单流程；它们不属于本阶段。

详细清单见：[阶段-4-商品收藏.md](阶段-4-商品收藏.md)。

## 重要约束

- 所有 SQL 使用参数化查询；不得拼接用户输入。
- 收藏列表必须联表一次查询商品摘要，避免 N+1 查询。
- 删除收藏必须同时以当前用户 ID 和商品 ID 作为条件，不能影响他人数据。
- 数据库唯一索引必须存在，即使 Service 做了重复收藏检查。
- 商品下架后不能新增收藏；已存在的收藏仍应可在收藏列表查看和取消。
- 不要在代码、文档、截图、Git 或接口导出中记录真实密码、Token、验证码、数据库凭据或 JWT 密钥。
