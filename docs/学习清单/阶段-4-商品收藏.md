# 阶段 4：商品收藏

## 目标

用户可以收藏、取消收藏、分页查看自己的收藏；同一商品不会被重复收藏。

## 本阶段文件地图

后端从根包 `com.campus.trade.campustradeserver` 新建：

```text
favorite/entity/Favorite.java
favorite/mapper/FavoriteMapper.java
favorite/service/FavoriteService.java
favorite/controller/FavoriteController.java
favorite/vo/FavoritePageResponse.java
```

SQL 文件：`campus-trade-server/src/main/resources/db/migration/V5__create_favorite.sql`。前端文件：`campus-trade-web/src/api/favorite.js`、`campus-trade-web/src/views/user/FavoriteListView.vue`。在已有商品卡片和商品详情页面中修改并加入收藏按钮，不要新建第二套商品详情页。

## 清单

- [ ] 创建 `favorite` 表：`id`、`user_id`、`product_id`、`created_at`；为 `(user_id, product_id)` 加唯一索引。
- [ ] 写接口文档：`POST /api/products/{productId}/favorite`、`DELETE /api/products/{productId}/favorite`、`GET /api/favorites?page=&pageSize=`。
- [ ] 规则确认：已收藏的商品即使下架仍可显示；只有 `ON_SALE` 商品允许新增收藏。
- [ ] 新增收藏时从登录用户获取 user ID，检查商品存在且在售；不接收前端传来的 user ID。
- [ ] 重复收藏建议做成幂等成功（方便前端），但数据库唯一索引必须保留。
- [ ] 删除时必须同时按当前 user ID 与 product ID 删除，不能删除别人的收藏。
- [ ] 收藏列表按收藏时间倒序分页，直接返回渲染商品卡片需要的商品摘要，避免一条收藏查一次商品的 N+1 查询。
- [ ] 可在商品详情/列表响应中返回 `favorited` 布尔值，但必须由后端根据当前用户计算。
- [ ] 在 Postman 的“收藏”文件夹手动保存并验证：新增、重复新增、删除、不存在删除、未登录、跨用户隔离、分页与商品状态。
- [ ] Vue：商品卡片和详情页添加收藏按钮；请求期间防止重复点击；只有后端成功后才更新本地状态。
- [ ] Vue：创建“我的收藏”，包含分页、跳商品详情、状态标签、加载/空/错误状态。
- [ ] 在浏览器手动点收藏、取消收藏并打开收藏页；运行 `npm run build` 后提交 Git。
