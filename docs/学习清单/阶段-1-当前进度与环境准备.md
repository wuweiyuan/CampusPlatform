# 阶段 1：当前进度与换电脑环境准备

> 最后更新：2026-08-13
>
> 本文只记录目前实际完成的内容。邮箱验证码、注册、登录、JWT 等功能**尚未开始编写**。

## 一、当前已完成

### 1. MySQL

本机已经创建数据库：

```sql
CREATE DATABASE campus_trade
DEFAULT CHARACTER SET utf8mb4
COLLATE utf8mb4_unicode_ci;
```

它的作用是存放后续的用户、商品、分类、收藏和订单表。

目前数据库中还没有业务表；`sys_user` 用户表会在下一步通过 Flyway SQL 脚本自动创建。

### 2. Redis

本机已经安装 Redis，采用本地安装方式，不是 Docker 容器。

后续 Spring Boot 默认连接信息计划为：

```text
主机：localhost
端口：6379
```

Redis 后面会保存：

- 邮箱验证码（5 分钟过期）
- 同一邮箱发送验证码的 60 秒冷却时间
- 已退出 JWT 的黑名单

还需要在终端运行下面命令，确认 Redis 服务已启动：

```bash
redis-cli ping
```

预期结果：

```text
PONG
```

### 3. 后端 Maven 依赖

已在 `campus-trade-server/pom.xml` 添加下列依赖：

| 依赖 | Maven artifactId | 用途 |
|---|---|---|
| MyBatis Plus | `mybatis-plus-spring-boot4-starter` | 后续通过 Mapper 操作 MySQL |
| MySQL 驱动 | `mysql-connector-j` | 让 Java 连接 MySQL |
| Redis | `spring-boot-starter-data-redis` | 让 Spring Boot 连接 Redis |
| Flyway MySQL | `flyway-mysql` | 项目启动时自动执行建表 SQL |

注意：项目当前使用 Spring Boot `4.1.0`，因此 MyBatis Plus 使用的是：

```xml
<artifactId>mybatis-plus-spring-boot4-starter</artifactId>
```

不要改回 `boot3` starter。

## 二、换一台电脑时需要准备什么

### 1. 基础软件

先安装并确认以下软件可用：

| 软件 | 当前项目要求 | 验证命令 |
|---|---|---|
| JDK | 17 或更高 | `java -version` |
| Maven | 可用即可；项目也有 Maven Wrapper | `mvn -version` |
| Node.js | 20.19.5 | `node -v` |
| npm | 与 Node 一起安装 | `npm -v` |
| MySQL | 本地可启动 | `mysql --version` |
| Redis | 本地可启动 | `redis-cli ping` |
| Git | 推荐安装 | `git --version` |

前端项目已经声明 Node 版本，文件在：

```text
campus-trade-web/.nvmrc
```

文件内容是：

```text
20.19.5
```

### 2. 复制或克隆项目后安装前端依赖

进入前端目录：

```bash
cd campus-trade-web
```

安装依赖：

```bash
npm install
```

验证前端可以构建：

```bash
npm run build
```

### 3. 创建 MySQL 数据库

登录 MySQL：

```bash
mysql -u root -p
```

进入 MySQL 后执行：

```sql
CREATE DATABASE campus_trade
DEFAULT CHARACTER SET utf8mb4
COLLATE utf8mb4_unicode_ci;
```

检查：

```sql
SHOW DATABASES;
```

列表中应有：

```text
campus_trade
```

### 4. 启动并验证 Redis

先按你所用操作系统的方式启动 Redis 服务，然后执行：

```bash
redis-cli ping
```

必须看到：

```text
PONG
```

### 5. 后端依赖下载

进入后端目录：

```bash
cd campus-trade-server
```

执行：

```bash
./mvnw package -DskipTests
```

Windows PowerShell 使用：

```powershell
.\mvnw.cmd package -DskipTests
```

说明：这一步仅下载 Maven 依赖并检查后端是否能打包；目前还没有配置 MySQL 和 Redis 连接，所以不要期待认证功能可用。
