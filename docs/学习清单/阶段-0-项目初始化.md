# 阶段 0：项目初始化

## 目标

建立能独立启动、能联调的 Spring Boot 和 Vue 3 项目。此阶段不写用户、商品、JWT、Redis、Docker 等业务功能。

## 最终验收

浏览器打开 Vue 页面后，显示“后端状态：UP”；请求经过 Vite 代理访问 `GET /api/health`。

## 清单

### 1. 检查本机环境

- [ ] 运行 `java -version`，确认 Java 17 或更高。
- [ ] 运行 `mvn -version`，确认 Maven 可用。
- [ ] 运行 `node -v`、`npm -v`，记录版本。
- [ ] 运行 `git --version`，确认 Git 可用。
- [ ] 运行 `docker --version`；没有也没关系，记录下来，阶段 9 再处理。

### 2. 初始化 Git 与项目说明

- [ ] 在项目根目录运行 `git init`。
- [ ] 创建 `.gitignore`，至少忽略：后端 `target/`、前端 `node_modules/` 和 `dist/`、`.idea/`、`.vscode/`、`.DS_Store`、`.env`、日志、`.superpowers/`。
- [ ] 新建 `README.md`，写明项目名称、学习目的、后端目录、前端目录、已检查的环境版本。
- [ ] 建立 `docs/api/phase-0.md`，记录健康检查接口：`GET /api/health`，无需登录，返回：

```json
{
  "code": 0,
  "message": "ok",
  "data": { "status": "UP" }
}
```

- [ ] 第一次提交：`git add . && git commit -m "docs: 初始化项目说明"`。

### 3. 创建 Spring Boot 后端

- [ ] 用 Spring Initializr 创建 Maven 项目：Group `com.campus`，Artifact `campus-trade-server`，包名 `com.campus.trade`，Java 17，Spring Boot 3.x。
- [ ] 初始依赖只选：Spring Web、Validation、Lombok、Spring Boot Test。
- [ ] 目录放在 `campus-trade-server/`。
- [ ] 创建通用返回类 `ApiResponse<T>`，字段为 `code`、`message`、`data`；提供 `success(data)`，固定返回 `code=0`、`message="ok"`。
- [ ] 创建 `HealthController`：类上 `@RestController`、`@RequestMapping("/api")`，提供 `GET /health`，返回 `ApiResponse.success(Map.of("status", "UP"))`。
- [ ] 先写 `HealthControllerTest`：断言 HTTP 200、`$.code=0`、`$.message="ok"`、`$.data.status="UP"`。
- [ ] 先运行 `./mvnw test -Dtest=HealthControllerTest`，确认在未实现接口时失败；实现后再次运行，确认成功。
- [ ] 创建 `BusinessException`（带业务错误码）和 `GlobalExceptionHandler`。约定参数错误返回 HTTP 400、`code=400`、`message="请求参数不合法"`。
- [ ] 在 `application.yml` 只配置端口 `8080`、应用名、JSON 非空字段不序列化；不配置数据库、Redis、SMTP、JWT 密钥。
- [ ] 运行 `./mvnw test`，通过后提交：`git commit -m "feat(server): 添加健康检查接口"`。

### 4. 创建 Vue 前端

- [ ] 用 `npm create vite@latest campus-trade-web -- --template vue` 创建 Vue 项目。
- [ ] 在运行任何 npm 安装、构建、测试命令前，检查 `.nvmrc`、`.node-version`、`package.json` 的 `engines` 或 `volta` 是否指定 Node 版本；若未指定，把实际 Node 版本写进 README。
- [ ] 安装：`element-plus`、`axios`、`vue-router`；开发测试依赖：`vitest`、`jsdom`、`@vue/test-utils`。
- [ ] 创建 Axios 实例 `src/api/http.js`：`baseURL: '/api'`，超时 10 秒。
- [ ] 在 `vite.config.js` 配置 `/api` 代理到 `http://localhost:8080`，并保留 `/api` 前缀。
- [ ] 创建根路由 `/` 与 `HealthView.vue`；页面加载时请求 `http.get('/health')`，成功显示“后端状态：UP”，失败显示“后端不可用”。
- [ ] 在 `main.js` 注册 Element Plus 和路由；`App.vue` 只渲染 `<RouterView />`。
- [ ] 为 `HealthView` 写组件测试：模拟 `/health` 返回成功结果，断言页面包含“后端状态：UP”。
- [ ] 运行 `npm test` 和 `npm run build`，两项都通过后提交：`git commit -m "feat(web): 添加健康检查页面"`。

### 5. 联调验收

- [ ] 终端 1：在 `campus-trade-server/` 运行 `./mvnw spring-boot:run`。
- [ ] 终端 2：运行 `curl -i http://localhost:8080/api/health`，确认响应与 API 文档一致。
- [ ] 终端 3：在 `campus-trade-web/` 运行 `npm run dev`，打开 Vite 打印的地址。
- [ ] 页面显示“后端状态：UP”；浏览器网络请求应为前端域名下的 `/api/health`，不能在代码中写死 `localhost:8080`。
- [ ] 在 README 记录真实可用的启动、测试和构建命令，并提交验收记录。
