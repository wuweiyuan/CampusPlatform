import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;

#### 3.4 创建公共异常约定（完成 3.3 后再做）

**为什么现在做：** 后面注册、发布商品时会出现“验证码错了”“价格不合法”这类错误。我们不希望每个 Controller 都手写一遍返回 JSON；这两个类让 Spring 统一处理。它们现在暂时不会被调用，这很正常。

- [x] **你已经创建的文件 1**：`campus-trade-server/src/main/java/com/campus/trade/campustradeserver/common/exception/BusinessException.java`。
- [x] **你已经创建的文件 2**：`campus-trade-server/src/main/java/com/campus/trade/campustradeserver/common/exception/GlobalExceptionHandler.java`。
- [ ] **写入 `BusinessException.java` 的完整代码**：

```java
package com.campus.trade.campustradeserver.common.exception;

import lombok.Getter;

@Getter
public class BusinessException extends RuntimeException {

    private final Integer code;

    public BusinessException(Integer code, String message) {
        super(message);
        this.code = code;
    }
}
```

- [ ] **写入 `GlobalExceptionHandler.java` 的完整代码**：

```java
package com.campus.trade.campustradeserver.common.exception;

import com.campus.trade.campustradeserver.common.api.ApiResponse;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.MethodArgumentNotValidException;
import org.springframework.web.bind.annotation.ExceptionHandler;
import org.springframework.web.bind.annotation.RestControllerAdvice;

@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(BusinessException.class)
    public ResponseEntity<ApiResponse<Void>> handleBusinessException(
            BusinessException exception
    ) {
        return ResponseEntity.badRequest().body(
                new ApiResponse<>(exception.getCode(), exception.getMessage(), null)
        );
    }

    @ExceptionHandler(MethodArgumentNotValidException.class)
    public ResponseEntity<ApiResponse<Void>> handleValidationException(
            MethodArgumentNotValidException exception
    ) {
        return ResponseEntity.badRequest().body(
                new ApiResponse<>(400, "请求参数不合法", null)
        );
    }
}
```

- [ ] **代码意思**：`BusinessException` 是自定义错误，例如未来写 `throw new BusinessException(1001, "验证码错误或已过期")`；`@RestControllerAdvice` 意为“捕获所有 Controller 抛出的异常并返回 JSON”；`@ExceptionHandler(...)` 指定处理哪一种异常；`Void` 表示错误响应没有 `data` 内容。
- [ ] **本步骤完成标志**：两个文件没有红线；先不需要专门触发错误测试。继续运行健康接口时仍能正常返回 `UP` 就够了。
