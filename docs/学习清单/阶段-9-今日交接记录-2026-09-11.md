## 验证码与日志说明

当前验证码只生成并存入 Redis，不发送真实邮件。日志只记录生成与缓存事件，不打印验证码；部署容器不会自动实现 SMTP。

本机学习验收时，先在注册页申请验证码，再在项目根目录查询（替换示例邮箱，不记录真实验证码）：

```bash
docker compose --env-file deploy/.env -f deploy/docker-compose.yml exec redis sh -c 'REDISCLI_AUTH="$REDIS_PASSWORD" redis-cli GET "auth:email-code:你的邮箱@example.com"'
```

验证码有效期 5 分钟；返回 `(nil)` 表示不存在或已过期。此方式仅用于当前本机验收，正式开放注册前应完成 SMTP。

查看后端日志：

```bash
docker compose --env-file deploy/.env -f deploy/docker-compose.yml logs --tail=100 -f server
```

Ctrl+C 只退出日志跟踪，不停止服务。
