## 下次第一步：创建 `LoginResponse`

文件位置：

`campus-trade-server/src/main/java/com/campus/trade/campustradeserver/auth/dto/LoginResponse.java`

用途：登录成功后返回 JWT、Token 类型、过期秒数，以及不会暴露密码的用户信息。

```java
package com.campus.trade.campustradeserver.auth.dto;

import lombok.Data;

@Data
public class LoginResponse {

    private String token;
    private String tokenType;
    private long expiresIn;
    private UserInfoResponse user;
}
```
