## 明天的第一步：创建 SendEmailCodeRequest

### 为什么做

发送验证码接口会收到邮箱；`SendEmailCodeRequest` 用来接收邮箱，并自动校验格式。

### 文件位置

`campus-trade-server/src/main/java/com/campus/trade/campustradeserver/auth/dto/SendEmailCodeRequest.java`

### 在 IDEA 中怎么创建

1. 展开 `src/main/java/com.campus.trade.campustradeserver/auth/dto`。
2. 如果还没有 `auth.dto`：右键根包 `com.campus.trade.campustradeserver` → `New` → `Package` → 输入 `auth.dto`。
3. 右键 `auth.dto` → `New` → `Java Class` → 输入 `SendEmailCodeRequest`。
4. 用下面完整代码替换文件内容。

```java
package com.campus.trade.campustradeserver.auth.dto;

import jakarta.validation.constraints.Email;
import jakarta.validation.constraints.NotBlank;

public class SendEmailCodeRequest {

    @NotBlank(message = "邮箱不能为空")
    @Email(message = "邮箱格式不正确")
    private String email;

    public String getEmail() {
        return email;
    }

    public void setEmail(String email) {
        this.email = email;
    }
}
```
