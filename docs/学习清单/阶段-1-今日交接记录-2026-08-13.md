- [x] 已创建 `SecurityConfig`：

  - 发送验证码、注册和登录接口允许匿名访问，其余接口要求认证。
  - 将 JWT 过滤器注册在 `UsernamePasswordAuthenticationFilter` 之前。

  - 提供 `isBlacklisted(String jti)` 查询方法。

## 当前项目关键配置

- 后端目录：`campus-trade-server`
- Java 根包：`com.campus.trade.campustradeserver`
- MySQL：`localhost:3306/campus_trade`
- Redis：`localhost:6379`
- 后端端口：`8080`
- 用户表：`sys_user`
- 邮箱验证码 Key：`auth:email-code:{email}`，有效期 5 分钟
- 发送冷却 Key：`auth:email-code:cooldown:{email}`，有效期 60 秒
- JWT 默认有效期：7200 秒
- JWT 黑名单 Key：`auth:token:blacklist:<jti>`
