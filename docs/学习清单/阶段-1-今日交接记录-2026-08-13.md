## 下次第一步：创建 TokenBlacklistService

创建文件：

`campus-trade-server/src/main/java/com/campus/trade/campustradeserver/auth/security/TokenBlacklistService.java`

职责：

1. 注入 `StringRedisTemplate`。
2. 提供将 Token 加入黑名单的方法，参数至少包含 `jti` 和 JWT 剩余有效期。
3. Redis Key 固定使用：`auth:token:blacklist:{jti}`。
4. Redis Value 可以使用固定字符串 `1`。
5. Key 的 TTL 必须等于 JWT 剩余有效期，不能永久保存。
6. 提供 `isBlacklisted(String jti)`，供 `JwtAuthenticationFilter` 每次认证时查询。

完成服务后再按以下顺序继续：

1. 在过滤器中解析 `jti` 并检查 Redis 黑名单。
2. 在 `AuthService` 中实现退出业务，计算 Token 剩余有效期并写入黑名单。
3. 在 `AuthController` 中实现 `POST /api/auth/logout`。
4. 测试退出后旧 Token 访问 `/api/auth/me` 返回 401。
