## 下次第一步：接入注册接口

1. 删除 `AuthService.java` 中无用的 `import java.sql.Wrapper;`。
2. 修改以下文件：

`campus-trade-server/src/main/java/com/campus/trade/campustradeserver/auth/controller/AuthController.java`

需要添加：

```java
import com.campus.trade.campustradeserver.auth.dto.RegisterRequest;
import com.campus.trade.campustradeserver.auth.service.AuthService;
```

在 `AuthController` 中注入：

```java
private final AuthService authService;
```

然后新增注册接口：

```java
@PostMapping("/register")
public ApiResponse<Void> register(
        @Valid @RequestBody RegisterRequest request
) {
    authService.register(request);
    return new ApiResponse<>(0, "注册成功", null);
}
```

完成后使用 Apifox/Postman 测试完整流程：先获取邮箱验证码，再携带验证码调用 `POST /api/auth/register`，最后检查 `sys_user` 中的密码是否为 BCrypt 哈希而不是明文。

## 当前项目关键配置

- 后端目录：`campus-trade-server`
- Java 根包：`com.campus.trade.campustradeserver`
- MySQL 数据库：`campus_trade`，地址 `localhost:3306`
