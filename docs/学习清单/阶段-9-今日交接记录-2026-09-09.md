## 今日停止状态与下次启动

以下命令均在项目根目录执行。

助手已于今日实际执行成功，四个容器均返回 Stopped：

```bash
docker compose --env-file deploy/.env -f deploy/docker-compose.yml stop
```

该命令仅停止本项目服务，不退出 Docker Desktop，也不删除数据。

下次确认 Docker 引擎运行后执行：

```bash
docker compose --env-file deploy/.env -f deploy/docker-compose.yml up -d
docker compose --env-file deploy/.env -f deploy/docker-compose.yml ps
curl -i http://localhost/api/health
```

未改代码时不需要 `--build`。需要重新构建时在 `up -d` 后加 `--build`，会执行后端打包及前端构建。

排查运行问题可查看：

```bash
docker compose --env-file deploy/.env -f deploy/docker-compose.yml logs --tail=100 server nginx
```
