# 阶段 2：交接记录（更新于 2026-08-19）

> 阶段二的前端主体已实现，并已完成核心登录与权限浏览器验收。下一步先完成注册链路和 Node 20 下的构建验收；阶段二清单保持原样，不在清单文件中更新复选框。

## 本次新增

### 认证状态与请求封装

- 已安装 `pinia`，并新增 `src/stores/pinia.ts` 与 `src/stores/auth.ts`。
- 状态只保存 JWT Token 和脱敏用户信息：`id`、`username`、`email`、`role`。
- Token 和用户信息存入 localStorage；刷新时恢复；主动退出或收到 HTTP 401 时同时清空。
- 新增 `src/api/auth.ts`，包含发送验证码、注册、登录、获取当前用户、退出五个请求方法。
- `src/api/http.ts` 已添加：
  - Token 请求拦截器；
  - 401 响应时清理会话并跳转登录页；
  - 保留登录、注册、发送验证码请求，避免其失败时发生错误跳转；
  - `getErrorMessage` 统一提取后端错误提示。

### 路由与页面

- 新增公开路由：`/login`、`/register`、`/403`、`/404`。
- 已为首页、个人中心及后续功能占位页添加登录保护；未登录时跳转 `/login?redirect=原地址`。
- 已预留 `/admin`，普通 `USER` 访问会进入 `/403`；管理员页面将在阶段六实现。
- 已新增登录、注册、个人中心、403、404、登录后公共布局及后续功能占位页面。
- 注册页包含与后端一致的基础参数校验、提交禁用和 60 秒验证码倒计时。
- 登录成功后使用新 Token 请求 `/api/auth/me`，仅保存接口返回的可信用户信息。
- 新增前端路由与认证说明：[docs/web/phase-2.md](../web/phase-2.md)。
