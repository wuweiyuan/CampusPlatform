# 校园二手交易平台：完整自学路线

> 你亲自写代码；每完成一个阶段，再开始下一个阶段。每一阶段都需要：接口自测、前端联调、记录问题、Git 提交。

## 阶段顺序

| 阶段 | 学习目标 | 后端重点 | 前端重点 | 通过标准 |
|---|---|---|---|---|
| 0 | 初始化 | Spring Boot 骨架、统一返回、异常处理 | Vue 3 骨架、Axios、路由、代理 | 前端能调用 `/api/health` |
| 1 | 认证 | 邮箱验证码、注册、JWT 登录、退出 | 暂不接页面 | Apifox 可完成注册、登录、退出 |
| 2 | 前端登录与权限 | 获取当前用户、角色授权 | 注册/登录页、Token、路由守卫、动态菜单 | 学生不能访问管理员路由/API |
| 3 | 商品 | 分类、商品 CRUD、搜索、分页、图片校验 | 商品广场、详情、发布、我的发布 | 用户只能维护自己的在售商品 |
| 4 | 收藏 | 收藏关系、去重、分页 | 收藏按钮、我的收藏 | 无法重复收藏，数据只属于本人 |
| 5 | 订单 | 事务下单、取消、模拟付款、确认完成 | 下单与订单列表 | 一件商品不会被重复购买 |
| 6 | 管理台 | 管理员管理分类、用户、商品、订单 | 同项目动态管理员菜单与管理页 | 普通学生的管理员请求返回 403 |
| 7 | Redis | 分类、热门商品缓存与失效 | 热门商品区 | 能看到缓存命中、失效和回填 |
| 8 | 质量 | 测试、错误码、日志、README | 加载/空/错误状态、基础适配 | 从注册到交易完成可复现 |
| 9 | 部署 | Dockerfile、Compose、环境变量 | 构建产物由 Nginx 提供 | 一条 Compose 命令后可访问 |

## 每阶段固定流程

1. 在 `docs/api/` 先写：接口地址、请求参数、响应字段、权限、错误情况。
2. 涉及数据时先写 SQL 迁移和表结构说明。
3. 先写一个失败测试，或在 Apifox 保存一条预期失败的请求。
4. 完成后端 Controller → Service → Mapper。
5. 用 Apifox 测试：正常、未登录、越权、参数错误。
6. 再接 Vue 页面，处理加载、空列表、请求失败。
7. 通过后提交 Git；提交信息写清做了什么。
