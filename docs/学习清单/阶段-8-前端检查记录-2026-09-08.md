## 问题 1：窄屏缺少导航入口

- 390×844 视口下，侧栏隐藏；顶部只剩用户名与退出，没有菜单按钮或替代导航。
- 管理员商品页实测可见导航链接数量为 0。进入某页后无法通过页面导航切换收藏、订单或管理模块。
- 依据：`campus-trade-web/src/style.css` 的 760px 媒体查询隐藏 sidebar；`src/layouts/AppLayout.vue` 没有移动导航入口。
- 建议：增加移动菜单，复用当前路由和角色规则；验证打开、关闭、切换页面及 USER/ADMIN 菜单差异。

## 问题 2：退出请求失败仍提示成功

- 在浏览器中仅模拟请求失败，点击顶部“退出”。页面清除本地会话并回到首页，同时显示“已退出登录”。
- 使用点击前的同一个 Token 直接请求后端 `/api/auth/me`，仍返回 HTTP 200，证明后端 Token 尚未撤销。
- 依据：`AppLayout.vue` 的 `handleLogout` 吞掉异常，在 finally 中无条件提示成功；这与后端退出写入失败返回 503 的明确语义不一致。
- 建议：区分本地会话清除和服务端退出成功。失败时明确说明服务端退出未完成，不使用成功提示；是否保留会话供重试在修改时明确。
