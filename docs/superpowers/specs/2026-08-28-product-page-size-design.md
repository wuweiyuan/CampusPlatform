# 商品分页条数选择设计

商品广场与“我的发布”使用一致的分页行为：默认每页 10 条，提供 10、20、30、50 四种条数。选择器使用 Element Plus `el-pagination` 的 `sizes` 布局，并通过 `page-sizes` 限定选项。

两个页面将 `pageSize` 作为响应式状态传给各自 API。用户切换条数时，页面将页码重设为 1 后重新请求；分类、关键词和状态筛选保持不变。后端已接受最大 50 的 `pageSize`，因此不修改后端契约。

测试覆盖默认请求的 `pageSize: 10` 和切换条数后携带新大小、页码为 1 的行为；完成后运行现有 Vitest 测试和生产构建。
