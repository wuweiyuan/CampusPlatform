# 校园二手交易平台：自学执行路线

> 本路线由你亲自实现；每个阶段完成后再进入下一阶段。遇到设计、报错或 review 需求时，提交对应文件或错误信息即可。

## 实施顺序

| 计划 | 目标 | 前置条件 | 阶段产物 |
|---|---|---|---|
| 00 初始化 | 建立可启动、可联调的前后端骨架 | 无 | 后端 health API、前端健康页、开发环境说明 |
| 01 注册登录 | 邮箱验证码、注册、登录、JWT、退出 | 00 | 可登录的用户与 Token；见 [阶段 1](2026-08-13-campus-trade-phase-1-authentication.md) |
| 02 前端认证 | 登录注册页面、会话、动态菜单与路由守卫 | 01 | 可从网页完成登录与受保护路由跳转；见 [阶段 2](2026-08-13-campus-trade-phase-2-web-auth.md) |
| 03 商品分类与商品 | 分类、商品表与商品 CRUD/搜索 | 01 | 商品广场、详情、发布、我的发布；见 [阶段 3](2026-08-13-campus-trade-phase-3-catalog.md) |
| 04 收藏 | 收藏关系与收藏页 | 03 | 商品收藏闭环；见 [阶段 4](2026-08-13-campus-trade-phase-4-favorites.md) |
| 05 订单 | 事务下单、取消、模拟付款、完成 | 03 | 单件商品交易闭环；见 [阶段 5](2026-08-13-campus-trade-phase-5-orders.md) |
| 06 管理台 | 管理员对分类、用户、商品、订单的管理 | 02、03、05 | 同一 Vue 项目的管理员菜单和页面；见 [阶段 6](2026-08-13-campus-trade-phase-6-admin.md) |
| 07 Redis 完善 | 分类/热门缓存与失效策略 | 03、05 | 可观测的缓存命中与失效；见 [阶段 7](2026-08-13-campus-trade-phase-7-redis.md) |
| 08 质量 | 测试、错误码、日志、README、页面状态 | 01–07 | 可复现的验收记录；见 [阶段 8](2026-08-13-campus-trade-phase-8-quality.md) |
| 09 部署 | Docker Compose、Nginx、Linux 验证 | 08 | 一键部署的可访问服务；见 [阶段 9](2026-08-13-campus-trade-phase-9-deployment.md) |

## 每个阶段的固定循环

1. 先在 `docs/` 写出表字段、接口清单、状态变化与权限归属。
2. 先写一个能失败的后端测试或在 Apifox 保存一个预期失败的用例。
3. 完成最小后端实现，并验证正常、未登录、越权、参数错误四种请求。
4. 再接入对应 Vue 页面，处理加载、空数据与请求失败。
5. 在 README 或阶段记录写下启动方式、已知限制和验收截图/请求集合。
6. 在 Git 仓库中提交一次小而清晰的提交；建议每个可独立运行的功能一个提交。

## 当前入口
